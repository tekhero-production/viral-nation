# SEO Guide

## Route-Level Metadata
While this prototype is currently configured as an SPA, production deployment of this repository supports Angular SSR (Server-Side Rendering). 

For future extensions:
1. Use Angular's \`Meta\` and \`Title\` services in each Route Component's \`ngOnInit\`.
2. Configure \`OpenGraph\` data for sharing (og:title, og:image, twitter:card).

## Semantic Hierarchy
- **H1 Constraints:** Every page MUST feature exactly one \`<h1>\` tag representing the core value proposition of that page.
- **H2-H4 Usage:** Section breaks strictly use \`h2\` and \`h3\`. Labeling utilizes `h4` with all-caps styling.

## Content & Keyword Targets
- **Home:** Influencer marketing strategy, Creator-led campaigns.
- **Live TikTok:** TikTok Live commerce, real-time live selling.
- **About Us:** Influencer marketing agency, growth partner.
- **Talents:** Premium creators, brand partnerships.
- **Partners:** Enterprise influencer strategy, ambassador campaigns.
