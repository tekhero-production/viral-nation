# Viral Nation - Premium Influencer Marketing

A cinematic luxury multi-page website built for Viral Nation, showcasing premium influencer marketing and TikTok Live campaigns.

## Overview
- **Goal:** Drive sales and inquiries from businesses seeking top-tier creator campaigns.
- **Creative Direction:** Cinematic Luxury (Dark surfaces, muted metallic gold accents, sophisticated typography).
- **Tech Stack:** Angular v21+ (Zoneless), Tailwind CSS v4, Motion (for scroll animations).

## Running the Application
The applet automatically runs on port 3000 in the provided sandbox environment.

\`\`\`bash
npm run dev
\`\`\`

## Core Features
1. **Cinematic Hero Sections:** High-contrast, dynamic headers engineered for impact.
2. **WebGL Particle Overlay:** Elegant, subdued metallic dust using a custom lightweight canvas directive.
3. **Smooth Scroll Revelations:** Powered by \`motion\` for cinematic fading and entrance pacing.
4. **Curated Talent Grid:** High-end hover aesthetics displaying featured creators.
5. **Secure Inquiry Form:** Polished lead generation structure on the contact page.
